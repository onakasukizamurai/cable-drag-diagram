# ケーブル抗力の水平成分

水平流を受ける斜めのケーブルについて、法線方向と軸方向の抗力、その水平成分を確認する図です。角度スライダーと区間選択で表示を変更できます。

θはケーブルと水平流のなす角度です。平行が0°、直角が90°です。図は右下に傾くケーブルを扱い、流速は1 m/s、海水密度は1025 kg/m³です。表示する力はケーブル1 mあたりの値です。

水平力は次の式で計算します（0° ≤ θ ≤ 90°）。

```text
F_H = F_⊥ sinθ + F_∥ cosθ
F_⊥ = (1/2)ρ C_Dn D L (U sinθ)²
F_∥ = (1/2)ρ C_Da π D L (U cosθ)²
F_H = (1/2)ρ D L U² (C_Dn sin³θ + π C_Da cos³θ)
```

ρは海水密度、Dは外径、Lは区間長、Uは流速です。図ではL = 1 mとしています。法線方向には投影面積DL、軸方向には表面積πDLを使います。

| 区間 | 外径D（m） | 法線方向C_Dn | 軸方向C_Da |
| --- | ---: | ---: | ---: |
| 裸ケーブル | 0.116 | 1.2 | 0.008 |
| 浮力体付き | 0.361 | 2.617 | 0.345 |

この図は直線の微小区間にかかる抗力の分解を説明するものです。ケーブル全体の形状、海底接触、テザーや端部反力を解く張力解析は含みません。
